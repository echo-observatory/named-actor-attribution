Attribution annotator

Open a markup file (Open…, or drop files here) to start annotating.

Select text to create a segment, a distractor or an exclusion. Click a span to edit it. Nothing leaves this page: saving writes a file on your computer.

Shortcuts

Select text, then 1–9 to make it a segment of that speaker, D for a distractor, X for an exclusion. Selections snap to whole words; hold Alt while selecting for exact characters.

On a selected span: 1–9 assigns a speaker, Delete removes it, Esc deselects. Boundary buttons move by a word; with Shift, by a character.

Ctrl+Z undo, Ctrl+S save.
